# Document fallback font

The playground uses Carlito when Calibri is not installed. The regular, bold,
italic and bold italic faces preserve Calibri's advance widths and vertical
metrics. Local Calibri takes precedence. This fallback belongs to the playground;
library consumers still supply their own fonts or use embedded document fonts.

Source: https://github.com/googlefonts/carlito/tree/main/fonts/ttf
License: SIL Open Font License 1.1, included in OFL.txt.

The outlines differ from Calibri. Exact typography requires the original font.
