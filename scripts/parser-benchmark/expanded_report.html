    Original scoring details
    Original scores and charts remain available here. Image-node counts can undercount composite pictures. Exact table/cell text anchors reject added symbols, and per-run 5-grams are sensitive to run segmentation. The current measurements above match image payload occurrences, check span values at literal-content anchors, and check bold at aligned character offsets. Literal matching permits additional characters; it measures recall, not precision or layout.
    

    Quality across all attempted inputs, including parser failures
    These totals keep expected reference features for failed parses. They use every input for which the independent reference is available, a broader scope than the common comparison above.
    

    Raw grid-span equality is sensitive to resolved table grids, and short marked spans can be segmentation-sensitive. The legacy image score counts output nodes. The image-occurrence metric matches retained source payloads with the same reference and one-to-one rules for every measured parser, including composite placements and explicitly declared SVG alternatives. Neither measure establishes rendering fidelity. Original scores remain visible.
