What changed

Retained improvements

  • A document-scoped XML index with compact offsets and cached tag lookups.
  • Borrowed XML slices and cached formatting resolution, plus shared header/footer parsing.
  • Streaming run-text extraction with compatibility fallbacks.
  • Faster decompression with preallocated output and the existing decoder as a fallback.
  • Fewer copies of embedded assets and structured-block data.
  • Throughput-oriented Rust and WebAssembly release settings.

Why a gap remains

undoc reads selected ZIP parts and uses a streaming XML parser. Core also builds an editable model with source markup, formatting provenance, stable source references, and structured blocks.

The rewrite keeps those outputs. Shortcuts that failed equivalence or did not improve timings were discarded.

No cross-document cache, reduced extraction mode, or changed scoring oracle is used.
